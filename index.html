🔥 Configurer la synchronisation

Étapes (5 min, une seule fois) :
1. console.firebase.google.com → Créer un projet → nom : skymooz-weekplan
2. Menu gauche → Realtime Database → Créer une base → Mode test → Activer
3. Copie l'URL affichée en haut (ex: https://skymooz-weekplan-default-rtdb…app)
4. Onglet Règles → remplace tout par : {"rules":{".read":true,".write":true}} → Publier
